# Tic Tac Toe Frontend

A modern, minimalistic React implementation of a player-vs-player Tic Tac Toe game.

Features:
- Centered, responsive 3x3 board
- Player vs Player with alternating turns
- Status bar showing "Winner", "Draw", or "Next turn"
- Reset game button
- Light theme with custom color variables:
  - Primary: #1976d2
  - Secondary: #424242
  - Accent: #ffca28

Keyboard/Accessibility:
- Each square is a focusable button with ARIA labels
- Status uses aria-live="polite" for screen readers
